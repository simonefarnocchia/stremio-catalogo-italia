# Avvio HDMI

App per proiettori e TV Android TV / Google TV: all'accensione (e al risveglio dallo standby) passa da sola all'ingresso HDMI scelto.

- Trova gli ingressi del proiettore da sola; si può anche scegliere l'app che apre l'HDMI.
- Usa un servizio di Accessibilità, perché Android permette di aprire un'app dallo sfondo solo così. Non legge lo schermo: guarda solo quale app è in primo piano.
- Compilata da GitHub Actions a ogni modifica: l'APK è nell'ultima release.

Download breve: `catalogo-italia.onrender.com/hdmi`
